家教拾单 Windows 运行包 v0.2.4-rc.2（新界面与微信兼容测试版）

1. 将 ZIP 完整解压到自己的文件夹，不要只从压缩包内打开 EXE。
2. 双击 TutorAssistant.exe，浏览器会自动打开本地页面。
3. 在电脑版微信中登录自己的账号，在网页中确认授权、选择群聊，再点击提取。
4. 本地识别和筛选不需要 AI 或 API 密钥；通勤为可选功能，需自己的高德 Web 服务 Key。
5. 连接失败时，在启动窗口点击“检查微信兼容性（不读取聊天）”，将打开诊断文件夹；可以将其中两个 JSON 文件用于排查。
6. 关闭启动窗口会停止程序，关闭浏览器标签不会退出程序。

适用：Windows 10/11，64 位 x64；不需要安装 Python。微信版本兼容性仍需在目标客户端确认。
本发行包未进行数字签名。真实微信提取和真实高德路线没有在其他电脑逐一验证。
本版按实际界面与二进制特征适配微信4.1+ x64，不再只接受4.1.15.13；4.1.15.56尚待目标电脑实际读取验证，不代表所有4.1+版本均已通过。

数据存放：%LOCALAPPDATA%\TutorAssistant\data
升级只需解压新版本，不要覆盖或删除该数据目录。密钥由当前 Windows 用户加密，不能直接迁移给别人使用。
程序不会在启动、授权、刷新或本地筛选时自动查询高德，也不会自动联系订单发布者。

下载程序不附带作者聊天、收藏、出发点或密钥。请始终使用自己的微信账号和配置。
