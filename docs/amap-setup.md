# 高德通勤计算：申请与试用

通勤功能是可选项，不需要 AI。没有 Key 时，本地解析、微信授权、原文查看和筛选照常使用。接入已通过模拟接口测试，本轮未代用户查询真实地址或验收真实路线。

## 申请 Key

1. 在浏览器登录[高德开放平台控制台](https://console.amap.com/)，按平台要求完成开发者认证。
2. 在“应用管理 → 我的应用”创建应用。
3. 为应用添加 Key，服务平台选择 **Web 服务**。
4. 复制 Key，在本程序“通勤计算”页填写并保存。不是“Web端 JS API”，也不是 JS API 的安全密钥。
5. 在高德控制台检查所需接口的权限、月配额及账户计费设置。密钥配置、账号认证与服务协议由使用者自己完成；不要把 Key 发到聊天、Issue 或提交到 GitHub。

官方流程：[成为开发者并创建 Key](https://lbs.amap.com/api/webservice/create-project-and-key)。

## 先试一条路线

1. 在“通勤计算”选择公交、步行或驾车，保存设置。保存本身不调用高德。
2. 阅读地址使用说明，点击“同意并授权高德”。授权本次运行有效，与微信读取独立，不启用 AI。
3. 输入城市和明确学校、小区或道路位置，点击“查询并选择出发点”。核对返回结果，选择“设为出发点”。
4. 先把感兴趣的订单加入收藏，在“我的收藏”点击“计算通勤”，或打开收藏详情后点击“查询家教地点”。只有本地字段中的地点和城市会用于查询，不发送聊天全文、群名或发布者信息。
5. 将候选地点与原文核对，点击“用此位置计算”。即使只返回一个地点，也要手动确认，避免同名或错误定位。
6. 查看估算公里数、时间、起终点及查询时刻。结果不是上下课时刻的真实耗时，不改变原来的通过、待确认或排除状态。

列表优先显示详细授课地址，查询保留路名、路号、弄号和小区/学校等定位信息，剔除联系方式及楼栋单元、室号。仅当明确区县在本地区划表中的城市归属唯一时，才可为查询补足城市；不会使用出发点的城市猜测。原文只有区县、无法确定城市或高德只定位到市、区县等粗略中心时，不会冒充真实家教位置计算。

## 配额和费用

只对已收藏订单逐条计算，未收藏或取消收藏的订单在后台同样拦截。每次地点查询、路线计算均可能消耗配额。页面计数仅统计本次程序运行发起的高德请求，不是账户余额、实际账单或全部设备的用量。请以[高德控制台与官方计费说明](https://lbs.amap.com/upgrade)为准。

程序不读取设备位置；不会在启动、刷新、切换筛选条件时自动调用高德。请求按顺序限速，不自动重试；每次计算由你点击触发。没有配置账号充值、自动购买流量或技术服务许可的功能。

## 授权与数据

- 高德 Key 使用当前 Windows 用户的 DPAPI 独立加密，保存为数据库旁的 `*.amap-key.dpapi`，API 返回不包含 Key。
- 确认的出发点在本机保存，后续启动可继续选择使用，但需要重新授权位置请求。
- 路线结果及候选仅在短期内存中使用，不写入订单、不自动变更地址字段或筛选规则。
- 撤销授权后阻止后续请求并忽略在途响应；已经发往高德的位置和配额消耗无法撤回。
- 页面刷新、设置变化、出发点变化或撤销授权，会清除页面中的旧路线，避免显示过期结果。
- 可分别清除 Key 和出发点；这些操作不会删除原消息、收藏或模型配置。

## 常见问题

**提示 Key、权限或配额有问题**：确认 Key 的平台类型是 Web 服务，并在高德控制台检查接口权限、有效性、IP 限制和计费状态。本机页面地址是 `127.0.0.1`，但向高德发出的请求走电脑实际网络出口；如果设置 IP 白名单，应按高德规则填写实际出口 IP。


**地点不符或多个候选**：先核对原消息，不选择错误结果。如果原文信息不足，保留待确认，不拿出发点所在城市替代订单缺失的城市。

**没有路线**：可能是点位、交通方式、覆盖范围或服务权限问题，结果未取得时不会标记为满足通勤要求。
